# CSUCI Campus Navigation App — Brand Guidelines

## Design Vision

Create a modern, playful, coastal-inspired campus navigation experience for CSU Channel Islands students.

The application should feel welcoming, accessible, and easy to navigate while complementing CSUCI's updated university branding.

## Color Palette

| Color | HEX | Purpose |
|---|---|---|
| Channel Blue | #174A5D | Primary branding and headings |
| Ocean Teal | #45A6A4 | Buttons and interactive elements |
| Seafoam | #BCE5E1 | Cards and highlights |
| Warm Cream | #FFF8ED | Backgrounds |
| Sunset Orange | #F5B76E | Accent colors |

These are proposed app design colors. Verify official brand colors against CSUCI's published guidelines.

## Typography

Use clean, modern, readable fonts.

- Headings: Bold, welcoming, and easy to read.
- Body text: Simple and accessible.
- Buttons: Medium or semibold weight.

## UI Components

- Rounded buttons and cards
- Soft backgrounds
- Consistent spacing
- Friendly icons
- Simple bottom navigation
- Accessible color contrast

## Planned Screens

### Login Screen
- Welcoming message
- CSUCI-inspired colors
- University email validation
- Rounded login button

### Campus Map
- Interactive campus map
- Search functionality
- Colorful building markers
- Quick-access location categories

### Favorites
- Saved campus locations
- Simple list of favorite buildings

### Profile
- Account information
- App preferences
- Logout functionality

## Development Guidelines

- Use Kotlin Multiplatform and the project's existing UI framework.
- Keep styling reusable across screens.
- Preserve existing functionality.
- Follow GitHub feature-branch workflows.
- Do not modify official university logos.
- Explain proposed changes before implementing them.
