# App Branding

This folder contains the design guidelines for the CSUCI Campus Navigation App.

Our goal is to create a modern, playful, student-friendly interface inspired by the university's coastal identity.

## Files

- `BRAND_GUIDELINES.md` — Colors, typography, and UI design principles.

## Working With Codex

Before making visual changes, review `BRAND_GUIDELINES.md` and follow the established design guidelines.

Do not change existing functionality without approval.

All branding changes should be developed on a feature branch and reviewed through GitHub pull requests.
